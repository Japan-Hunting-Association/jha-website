# 国際化 (i18n) ガイド

## 概要

JHA Websiteは日本語と英語の2言語に対応しています。Astroの組み込みi18n機能を使用して、効率的な多言語サイトを実現しています。

## 設定

### Astro設定

```javascript
// astro.config.mjs
export default defineConfig({
  i18n: {
    defaultLocale: "ja",
    locales: ["ja", "en"],
    routing: {
      prefixDefaultLocale: true  // /ja/*, /en/* のようにプレフィックスを付ける
    }
  }
});
```

## ユーティリティ関数

### 翻訳関数

```typescript
// src/i18n/utils.ts
import { ui, defaultLang } from './ui';

export function getLangFromUrl(url: URL) {
  const [, lang] = url.pathname.split('/');
  if (lang in ui) return lang as keyof typeof ui;
  return defaultLang;
}

export function useTranslations(lang: keyof typeof ui) {
  return function t(key: keyof typeof ui[typeof defaultLang]) {
    return ui[lang][key] || ui[defaultLang][key];
  }
}

export function getLocalizedPath(path: string, lang: string) {
  return `/${lang}${path}`;
}
```

### パス変換

```typescript
// src/i18n/utils.ts
export function getRelativeLocaleUrl(
  lang: string,
  path: string = '',
  base: string = '/'
): string {
  const cleanPath = path.replace(/^\//, '');
  return `${base}${lang}/${cleanPath}`;
}

export function removeLocaleFromPath(path: string): string {
  const segments = path.split('/').filter(Boolean);
  if (segments[0] === 'ja' || segments[0] === 'en') {
    segments.shift();
  }
  return '/' + segments.join('/');
}
```

## 動的ルートでのi18n

### getStaticPathsでの言語対応

```astro
---
// src/pages/[lang]/topic/[slug].astro
import { getCollection } from 'astro:content';
import { languages } from '@/i18n/ui';

export async function getStaticPaths() {
  const topics = await getCollection('topic');
  
  return Object.keys(languages).flatMap(lang => 
    topics.map(topic => ({
      params: { 
        lang, 
        slug: topic.slug 
      },
      props: { 
        topic,
        lang 
      }
    }))
  );
}

const { topic, lang } = Astro.props;
const t = useTranslations(lang);
---
```

### コンテンツコレクションの設定

```typescript
// src/content/config.ts
import { z, defineCollection } from 'astro:content';

const topicCollection = defineCollection({
  type: 'content',
  schema: z.object({
    title: z.string(),
    pubDate: z.date(),
    lang: z.enum(['ja', 'en']),
    translationKey: z.string(), // 言語間でコンテンツを紐付けるキー
  }),
});
```

## 日付と数値のフォーマット

### 日付フォーマット

```typescript
// src/utils/date.ts
export function formatDate(date: Date, lang: string): string {
  const options: Intl.DateTimeFormatOptions = {
    year: 'numeric',
    month: 'long',
    day: 'numeric'
  };
  
  return new Intl.DateTimeFormat(
    lang === 'ja' ? 'ja-JP' : 'en-US',
    options
  ).format(date);
}

// 使用例
// ja: 2025年1月27日
// en: January 27, 2025
```

### 数値フォーマット

```typescript
// src/utils/number.ts
export function formatNumber(num: number, lang: string): string {
  return new Intl.NumberFormat(
    lang === 'ja' ? 'ja-JP' : 'en-US'
  ).format(num);
}

export function formatCurrency(amount: number, lang: string): string {
  return new Intl.NumberFormat(
    lang === 'ja' ? 'ja-JP' : 'en-US',
    {
      style: 'currency',
      currency: lang === 'ja' ? 'JPY' : 'USD'
    }
  ).format(amount);
}
```

## パフォーマンス最適化

### 言語別ビルド

```javascript
// astro.config.mjs
export default defineConfig({
  i18n: {
    defaultLocale: "ja",
    locales: ["ja", "en"],
    routing: {
      prefixDefaultLocale: true,
      redirectToDefaultLocale: false
    }
  },
  // 言語別にビルドを最適化
  vite: {
    build: {
      rollupOptions: {
        output: {
          manualChunks: (id) => {
            if (id.includes('/ja/')) return 'ja';
            if (id.includes('/en/')) return 'en';
          }
        }
      }
    }
  }
});
```

## デバッグとテスト

### 翻訳キーの確認

```typescript
// src/utils/i18n-debug.ts
export function checkTranslationKeys() {
  const jaKeys = Object.keys(ui.ja);
  const enKeys = Object.keys(ui.en);
  
  const missingInEn = jaKeys.filter(key => !enKeys.includes(key));
  const missingInJa = enKeys.filter(key => !jaKeys.includes(key));
  
  if (missingInEn.length > 0) {
    console.warn('Missing translations in English:', missingInEn);
  }
  
  if (missingInJa.length > 0) {
    console.warn('Missing translations in Japanese:', missingInJa);
  }
}
```

## ベストプラクティス

1. **翻訳キーの命名**: ドット記法で階層化 (`nav.home`, `form.submit`)
2. **デフォルト言語**: 主要ユーザー層に合わせて設定
3. **URLの一貫性**: 全ページで言語プレフィックスを統一
4. **コンテンツの同期**: 言語間でコンテンツ構造を統一
5. **フォールバック**: 翻訳がない場合のデフォルト表示を用意
